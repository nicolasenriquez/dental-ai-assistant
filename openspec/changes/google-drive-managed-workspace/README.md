# google-drive-managed-workspace

Add `AUTH_MODE=local|google` with backend provider enforcement, authoritative Google identity, explicit federated-user persistence, shared Dental login finalization, and Google-mode same-account Drive binding. Google Sign-In uses an official GIS popup callback with same-origin JSON guards; Drive onboarding remains explicit POST-based `authorization_url` handoff. OAuth callback uses direct sanitized `400` for invalid security state and `303 See Other` with allowlisted results for valid success/provider/domain outcomes; `409` remains same-origin JSON-only. Patient-bound human-controlled Drive workspace sits beside clinical assistant. Google identity, Dental session, and Drive authorization remain separate. Managed remote destinations are UTF-8 TXT (`text/plain`); Markdown remains local authoring/presentation and imported Markdown normalizes to TXT.
